# dsh-agent-splash

> 在设置面板里换启动动画、调淡入淡出与显示项。
> **它是个播放器** —— 动画文件你自己放，它只负责播放与配置。

---

## 它防的是什么

**「装好了，但不知道它在放什么、从哪换」。**

启动画面这类东西的通病：

```
✓ 装的时候配好了
✗ 三个月后想换一张，得去翻配置文件在哪、字段叫什么
✗ 而它偏偏是【每次启动都会看到】的那一屏
```

**所以它做的是：把那个配置搬到设置面板里，并且给你一个文件列表让你选。**

---

## 它长什么样

```
设置 → 启动画面
 ├─ 动画文件      （从目录里列出候选，点一下预览）
 ├─ 淡入 / 淡出时长
 ├─ 显示项        （标题 / 副标题 / 进度条 各自开关）
 └─ 预览
```

**预览是它值钱的地方** —— 换启动动画的时候，
**你没法「先启动一次看看」**（那要重启）。所以它必须能在页面里给你看一眼。

---

## 装

```bash
dsh plugin --profile <name> add <path-to-this-package>
```

**装完要重启 DSH**（宿主半在启动时加载）。

### 一个可配项

```bash
SPLASH_CONFIG   配置文件路径（默认 <DSH_HOME>/splash.json）
SPLASH_DIR      动画文件目录
```

**★ 动画文件不在这个包里** —— 这是它和「主题包」的区别：
**它提供的是播放能力，不是内容。**

---

## 四个路由

```
GET  /agent-splash/api/config    读配置
POST /agent-splash/api/config    写配置
GET  /agent-splash/api/files     列出候选动画
GET  /agent-splash/api/preview   预览（代理本地文件）
```

★ **`preview` 是唯一一个会把本地文件内容吐给浏览器的接口** ——
所以它只允许列出来的那几个候选，**不接受任意路径**。

---

## 边界

```
✗ 不带动画资源 —— 你自己放
✗ 不启动时阻塞 —— 动画播不动就走默认背景，不卡住启动
✗ 不读任意路径 —— preview 只认候选列表里的文件
```
