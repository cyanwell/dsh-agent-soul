# dsh-agent-mobile-adapt

> 竖屏触摸设备上，把 Web GUI 收成手机 App 的形态。
> **不影响 PC 端** —— 这是它唯一的设计约束。

---

## 它防的是什么

**「能用」和「好用」在手机上不是一回事。**

同一个界面，鼠标和手指是两种操作：

```
鼠标：悬停、右键、精确点击 12px 的图标
手指：没有悬停、只有点，而目标小于 44px 就点不准
```

**所以移动端适配不是「缩小」，是「换一套排布」。**

---

## 它怎么做：只加一层覆盖

**核心约束：不改原有 DOM 结构。**

```
✗ 另写一套移动端组件  →  两份实现，迟早不一致
✓ 只在媒体查询下【覆写样式】→ 桌面那份是唯一的真相
```

**这样桌面端永远不会因为「改移动端」而坏。**

---

## 它做哪几件事

```
· 顶栏与侧边栏收成抽屉 / 底部导航
· 触摸目标放大到可点中的尺寸
· 消息区改成竖向流式，去掉横向滚动
· 某些只在桌面成立的浮层（比如桌宠那样的固定定位元素）整块隐藏
```

★ **最后那条的判据是**：一个东西如果是「装饰性的、且固定定位」，
在手机上它只会挡住内容 —— **那就该撤掉，而不是缩小。**

---

## 装

```bash
dsh plugin --profile <name> add <path-to-this-package>
```

**装完刷新页面即可**（它是纯客户端半）。

---

## 边界

```
✗ 不改 DOM 结构 —— 只加样式覆盖
✗ 不做「移动端专用功能」—— 只调整同一套界面的排布
✗ 不检测设备 —— 跟视口宽度走（响应式，不是 UA 嗅探）
```
