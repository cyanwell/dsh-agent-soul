# dsh-agent-compaction

> 给 DSH 内置的**兜底压缩**装上「门牌」——
> 让自动压出来的 checkpoint 也带得回原文。

---

## 它防的是什么

**压缩过的东西再也找不回来。**

DSH 的上下文压缩有两条路：

| | 谁在驱动 | 产物带不带指针 |
|---|---|---|
| **ACP / 模型驱动** | agent 自己写摘要 | ✅ 天然带 —— 它知道自己是从哪读的 |
| **`compaction-basic`（内置兜底）** | agent 没响应提示时**自动出手** | ❌ **不带** |

兜底那条为什么要命，看它的指令就明白了。它要求保留：

```
exact file paths / commands / error strings / numeric values / function signatures
```

**每一条都是「要写得准」，但没有一句要求标注「这话从哪来」。**

于是它写出来的东西**每一条都对，每一条都无从核对**。
你不会觉得丢了东西 —— **你只是不再想起它。**

**这个包补的就是那一句。**

---

## 它怎么做

不重写 LLM 调用、不碰落盘策略。**只加一段指针**，三步：

```
1. 覆盖 compactRegion —— 它的参数里就有 start/end seq，先记下来再交给 super
2. 覆盖 summarize    —— 调 super 拿到摘要，然后在【最前面】插一个 text block
3. 全程兜底          —— 任何一步出错都降级成「没加指针」，
                        ★ 绝不让压缩本身失败
```

---

## 门牌长什么样

```
log:session-5c6fa2d9-19d8-4bc2-b9e3-35008a5e1340#seq=8405
```

而 `agent.session.id` 的值正好是 `session-5c6fa2d9-...`，**一字不差** —— 所以拼得出来。

事后用**你自己的检索入口**打开它即可：

```
<你的检索命令> log:<会话>#seq=<起点>
```

★ **本包只负责【写指针】，不规定你用什么工具去【回取】。**
换一套检索系统也能用 —— 只要它认 `log:<会话>#seq=<n>` 这种形式。

★★ **想让它把命令也写出来，配 `SOUL_MEMQ`**（或 `MEMQ`）：

```
SOUL_MEMQ='node /path/to/memq.mjs'
```

- 配了 → 渲染成 `'<你的命令>' open log:<会话>#seq=<n>`
- 没配 → **只给指针**，加一句「用你自己的检索命令打开」

★ 没配时**不给命令**是有意的：假命令比没有命令更坏 —— 读的人会照着敲，
敲不通之后可能反过来怀疑门牌本身。宁可只说「用你那套」，也不假装知道它叫什么。

**记不住精确位置时怎么办？那条三级纪律是：**

```
① 能拿到精确位置 → 写精确位置
② 拿不到        → 写「位置未知」+ 容器标识 + 一个检索入口
③ 绝不猜        → 错的门牌比没有更坏
```

---

## ★ 往返校验：宁可不写，也不写错的

复原出来的范围**必须通过往返校验**才会被采用：

```
input.messages 的末条  ≡  session.deriveEventMessage(session.eventAt(end))
首条（或次条）        ≡  ...eventAt(start) 的文本
```

**对不上就丢掉门牌、退回降级式。**
宁可只说「会话号 + 检索入口」，也不写一个会引你去翻**无关原文**的位置。

**为什么这条这么严**：一个错的指针会让你**以为能找到，于是不去找** ——
那比「找不到」坏得多。

---

## 它不会让压缩失败

`compaction-basic` 里有一处检查要求「框好的摘要 < 被遮蔽原文」。

指针块约 **60–90 token**，而压缩比常态在 **10:1** 上下 —— 影响不到 3%。

真正危险的是压缩比本来就接近 1:1 的情况，
**那种情况不加指针也一样会抛**，所以指针不是把「本来成功」变成「失败」的原因。

**仍然保留 try/catch**：出错就原样返回，让兜底照常工作。

## 装

```bash
dsh plugin --profile <name> add <path-to-this-package>
```

**装完要重启 DSH**（宿主半只在进程启动时加载一次）。

### 前置

它挂在一个 **peerDependency** 上：

```json
"peerDependencies": { "@deepseek-ai/dsh-compaction-basic": "*" }
```

**这是故意的** —— 它扩展的是那个包的行为，不是替代它。
被扩展的包必须由你的 DSH 安装提供（而不是这个包自己带一个副本，
那会导致两份实现同时生效）。

**★ 判据**：装完之后，看兜底压出来的 checkpoint 里**有没有那个 `log:...` 指针块**。
有 → 生效了。
