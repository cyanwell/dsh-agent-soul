# self —— 自我层的装配与体检

> 把「最不能丢的那一页」装配好，并且**盯着它别退化成一本手册**。

---

## 它防的是什么

**指令预算满了会静默丢，而且先丢的是最宽泛的那些** —— 恰恰是「我是谁」「不能做什么」这类总纲。

所以要把最不能丢的抽出来，走另一条推送通道（预算更大、不会静默消失）。
那个通道由 `dsh-agent-memory` 插件负责每轮注入 —— **而这个工具负责另外两件事：装配，和体检。**

> ### ★ 装配本身太简单（拼几段字符串）。这个工具值钱的是**体检**。

---

## 三条判据（每条对应一种「无声的坏」）

```
① 不许有「详见某个文件」的指向
    ★ 因为它指向的地方可能会静默消失 —— 那时这一页就断了，而断的时候没有提示

② 不许超预算
    ★ 因为超了会被截，而截了是无声的

③ 活体段必须是自动生成的
    ★ 因为手写的那一段迟早会和事实不一致 —— 而不一致时你不会知道
```

**★ 这三条不是风格要求。** 它们的共同点是：**坏的时候都不出声。**

---

## 三分钟上手

```bash
# ① 体检
node self.mjs --check
#    ★ 验：三条判据逐条给结论；有问题时逐条指出行号

# ② 打印装配好的整页（骨架 + 自动生成的活体）
node self.mjs
#    ★ 验：活体段的时刻是「现在」，未结条数和账本对得上
```

**★ 还没写那一页的时候它不会替你写，它会告诉你该写什么：**

```
✗ 没有这一页：<你的工作区>/SELF.md
  ★ 先写一页「不变量」：我是谁 / 不能做什么 / 约束分几级 / 要查东西时去哪。
    这个工具不会替你写它 —— 那一页只能是你的。
```

---

## 那一页该长什么样

**两段，分工明确：**

```
（手写）不变量     我是谁 / 硬线 / 约束的两级 / 门在哪      ← 改动很少
## 活体（自动生成）  时钟 / 未结的活 / 索引状态             ← 每轮在变
```

**★ 分界线就是 `## 活体` 这一行** —— 它之后的内容由本工具生成，你手写多少都会被覆盖。

**★ 为什么必须分开**：不变量写死才便宜（前缀缓存）；
而时钟和未结每轮都在变 —— **两者混在一起，等于每轮都在重写整页。**

---

## 配置

```bash
SELF_FILE    那一页的路径（默认 <工作区>/SELF.md）
LEDGER       账本文件（默认 <工作区>/ledger.jsonl）—— 活体段从这儿读未结的活
SELF_BUDGET  预算（默认 12288 字节）
```

---

## 边界

```
✗ 不替你写那一页 —— 它只能是你的
✗ 不改账本 —— 只读
✗ 不做推送 —— 那是 dsh-agent-memory 的事；这个只管「装配 + 体检」
✗ 不判断内容对不对 —— 它只管那三条会无声坏掉的
```

---

## 和别的零件的关系

```
tools/ledger    账本 + 闸门    ← 活体段的「未结的活」从这里读
tools/gateway   门 + 索引      ← 活体段的「索引状态」可以接这里
tools/self      自我层          ← 你在这里
dsh-agent-memory（插件）        ← 负责把这一页每轮推进上下文
```
