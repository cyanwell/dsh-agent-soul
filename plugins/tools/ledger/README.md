# ledger —— 只追加账本 + 权限闸门

> 一个**写下去就改不了**的记录文件，加一个命令行工具。
> 它是整套架构的**脊柱**：没有它，记忆就只是一堆散落的文件。

---

## 它防的是什么

**「两个会话同时记东西，然后谁都说不清最终是什么」。**

一个共享记忆系统最危险的时刻，不是读不到，是**写坏**：

```
✗ 两个写者互相覆盖 —— 后写的赢，前一个的痕迹消失
✗ 加了锁 —— 锁会死、会忘、会在异常时留在那儿
✗ 用时间戳解决 —— 时钟不准、并发同秒
```

> ### ★ 所以它选了一条更笨也更硬的路：**文件只被追加，从不重写。**
> 各写各的行 → **不需要锁** → 读的时候按时间合并。

---

## 三分钟上手

**别先读文档，先做这五步，每步都有可验的东西：**

```bash
# ① 把这个目录放到你想放的地方
#    （比如 <你的工作区>/tools/ledger/）

# ② 写第一条
node ledger.mjs add fact "第一条记录" --ref "手动创建"
#    ★ 验：同级目录出现 ledger.jsonl，里面是一行 JSON

# ③ 看它支持哪些类型
node ledger.mjs types
#    ★ 验：列出八类记录的名字与用途

# ④ 读回来
node ledger.mjs list --limit 3
#    ★ 验：看到你刚才写的那条

# ⑤ （可选）换账本位置
set LEDGER=D:/别的地方/ledger.jsonl        # Windows
export LEDGER=~/别的地方/ledger.jsonl       # bash
```

**★ 到这一步你已经有账本了。** 剩下的都是围着它长出来的。

## 八个类型，和一条闸门

```
type        写什么                                      谁能写
────────────────────────────────────────────────────────────────
lead        主导权声明：「现在是我在做决定」             ★ 只有人指定
promise     承诺：「我答应你 X」                         ★ 只有当前主导
fact        事实：发生了什么
decision    决定：定了什么
shelved     搁置：这件事先放下
gain / loss 得 / 失
persona     人格与记忆的变更                            谁做谁写，改了要说
container   容器交接：这条会话退场了，产物在哪
```

**★★ 闸门在 `promise` 和 `lead` 上，而且它是**代码级的**：**

```bash
node ledger.mjs add promise "我保证…" --ref "出处"
# 如果这条会话没署过 lead → exit 3，写不进去
```

> ### ★ 设计意图：**不依赖「它记得不要写」，而依赖「它写不进去」。**
> 约定会失效，闸门不会。

**为什么只卡这两个**：其余六类是「事实性」的 —— 谁做的谁写，写错也只是记错。
而 `promise` 是**替别人做承诺**，`lead` 是**声明自己是决策者** ——
这两件事一旦被随便写，整个账本就失去了取证效力。

## 为什么「只追加」值钱

```
✓ 历史与现在是同一份数据 —— 你读到的任何结论，都还能找到它第一次被写下的那一行
✓ 不需要锁 —— 多写者天然安全（实测：上千个日志文件各自追加，零冲突）
✓ 具备取证效力 —— 「谁在何时说了什么」不可事后修改
```

**★ 代价**：文件会一直长大，而且**撤销要靠新写一条来覆盖**（不是删掉旧的）。
**这个代价是故意的** ——「改过什么、被什么推翻过」本身就是信息。

## 命令

```bash
node ledger.mjs types                      # 列出八类
node ledger.mjs add <type> "<概要>" --ref "<出处>" [--feel "<当时的感受>"]
node ledger.mjs list [--type <t>] [--limit N]
node ledger.mjs stats                      # 条数统计
```

**★ `--ref` 不是可选的礼貌** —— 它是这条记录**能不能被追溯**的分界。
一条没有出处的记录，和一个猜测没有区别。

**★ `--feel` 是可选的**，而且**故意不强制**：
不是每条记录都有感受，**有才写、没有就不写**。
（做成必填它就变成每次要交的作业，那就成了表演。）

---

## 边界

```
✗ 不做检索 —— 那是索引层的事（tools/gateway）
✗ 不做压缩 —— 账本永远不删旧行
✗ 不判断内容对错 —— 它只管「写下去不能改」
✗ 不自动清理 —— 长大了是你的数据长大了，不是垃圾
```
