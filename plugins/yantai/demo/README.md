## 它讲什么

一个长期跑的 agent 会碰到三种「没有症状的坏」：

- **忘得不吭声** —— 上下文一满就静默丢东西，它不会告诉你它忘了，你去问它，它给你编一个。
- **只想不做** —— 长上下文下推理开始低熵重复（「好。执行。好。」），预算烧光、正文一个字没有。
- **静默降级** —— 某个部件悄悄失效，没有任何报警，等你发现时已经坏了六小时。

视频讲的是这套东西怎么防住它们：**ECHO 回声**（门牌 / 门 / 哨兵）、**VITAL 稳态**
（三种资源各配传感器 + 执行器 + 设定点）、**回路保护**、**权限闸门**，
最后串成一个「生命架构」。

## 怎么做的（给想看技术的人）

每一屏是一个会自己画画的网页。给它一个毫秒数，它就画出那一刻的样子 ——
**同一个毫秒永远是同一画面**。所以不是「录屏」，是**逐帧算出来再拍下来**：

```
jumpTo(ms) 纯函数 → playwright 逐帧截图 → ffmpeg 接成片段 → 合成 + 混音
```

好处是任何一帧都能停住、能重来、能改；坏处是踩过两次「捕获说成功、其实拍的是旧版」的坑，
所以脚本里加了一道闸门：**中间帧小于 20 KB 就判失败**（全黑的 1080p PNG 只有 8 KB）。
