# dsh-agent-yantai

> 一块工作台：把「我现在是什么状态」摊开在一屏里。
> 上下文水位、未结的活、最近的账本、以及几扇门。

---

## 它防的是什么

**「状态散在四个地方，而你每次都要手动去问」。**

一个长期运行的 agent 有几件**每次动手前都该知道**的事：

```
· 上下文水位到哪了          （决定这一轮能不能干重活）
· 有没有上轮欠下的事没结     （别把承诺弄丢）
· 最近写了什么              （现在这件事接在哪条线上）
· 那几扇门怎么开            （命令是什么，别去翻文档）
```

**这四件事原本散在四个地方** —— 一个文件、一条命令、一段记忆、一份文档。
**于是「先看一眼状态」这件事，成本高到你不会做。**

> ### ★ 这个插件做的事，是把「先看一眼」的成本降到零。

---

## 它摊开什么

```
工作台
 ├─ 水位        ●  上下文用了多少（★ 服务商口径，唯一准的那把尺子）
 ├─ 未结的活     ○  承诺 / 搁置 —— 欠着的那些
 ├─ 最近账本     ○  最近几条记录
 └─ 几扇门       ○  点一下复制命令
```

**★ 「水位」那一栏的取数方式值得单独说**：它读的是**真正喂进模型的量**，
不是面板上那个「可见消息面」。**这两个数是两把尺子，混着看会得出错误结论** ——
（详见 `dsh-agent-compaction` 的 README：什么时候该压、什么时候不该压，取决于读的是哪把尺子。）

---

## 它和别的零件的关系

```
dsh-agent-memory   把状态【推进提示】里（agent 自己知道）
dsh-agent-yantai   把状态【摆在界面上】（人知道）
```

**★ 这是同一份状态的两种投递方式。** 两个都装的时候，
你和 agent 看的是**同一份读数**，不会各说各的。

## 装

```bash
dsh plugin --profile <name> add <path-to-this-package>
```

**装完要重启 DSH**（客户端入口图是启动时一次性组合的）。

### 可配项

全部走环境变量，**包里不含任何人的本机路径**。没配的那一格会在界面上明说
「未配置 + 怎么配」，不会静默显示成空白，也不会退回某台作者机器的路径去猜。

```bash
# 数据源（至少配一个，否则它只是一块空面板）
YANTAI_SOUL         工作区根目录（账本默认取 <它>/02-墨.jsonl）
YANTAI_LEDGER       账本文件完整路径（优先于从 YANTAI_SOUL 推导）
YANTAI_MEMORY       记忆目录（按 hub/memq.mjs、tools/mo.mjs 等常见布局探脚本）
YANTAI_QUERY        检索脚本完整路径（覆盖 YANTAI_MEMORY 探出来的那个）
YANTAI_MO           账本 CLI 完整路径

# 本机环境
DSH_HOME            DSH 家目录（水位读 <它>/storages/session_projcache/sessions；
                    没设则依次探 ~/.dsh/home、~/.dsh）
YANTAI_APPS_DIR     速达清单目录（默认用插件自带的 apps/，换机器自动跟着走）
YANTAI_NODE         Node 可执行文件（默认用当前进程的 node，其次 PATH 里的 node）
YANTAI_HOST         机器名（默认 os.hostname()）

# 算力节点（手机）
YANTAI_NODE_ORIGIN  手机服务经 adb forward 后的本机地址，例 http://127.0.0.1:8766
                    没配 = 「未配置」：不探测、不假设端口
```

**★ 至少配一个数据源，否则它只是一块空面板。** 它默认不去猜你的目录结构。

---

## 附带的两个脚本

```
scan-apps.ps1   扫本机已安装的应用 → apps/apps.json + 图标
focus-app.ps1   把一个已打开的窗口拉到前台
```

**★ 它们是「能力」，不是「数据」** —— 所以 `apps/` 目录里默认是空的，
`apps.example.json` 只给字段格式。**装上之后跑一次扫描，它就有你自己的了。**

## 边界

```
✗ 不带数据 —— 不预置任何应用清单、任何账本
✗ 不写状态 —— 只读与展示（改状态是别的零件的事）
✗ 不猜路径 —— 配了才读，没配就空着
✗ 不自动刷新到卡顿 —— 轮询有下限，且可关
```
