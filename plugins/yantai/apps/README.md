# apps/ —— 应用启动台的数据

**这个目录里没有清单。** 装上之后它是空的 —— 那是对的。

## 为什么空着

`apps.json` 和 `icons/` 是**从一台具体的机器上扫出来的**：

```
· 应用名与安装路径 —— 装了什么是那台机器的事实
· 图标 —— 从那些程序的 exe 里提取出来的
```

**那不属于这个插件。** 插件提供的是**扫描与启动的能力**，不是**某一份清单**。

## 怎么让它有内容

```powershell
# 扫本机已安装的应用，生成 apps.json 与图标
powershell -ExecutionPolicy Bypass -File ..\scan-apps.ps1
```

★ 扫完刷新页面即可。**`apps.example.json` 是格式示例**，看一眼就知道字段是什么。

## 字段

```json
{ "name": "显示名", "target": "可执行文件完整路径", "icon": "图标文件名（可空）" }
```

★ `icon` 为空时界面用首字母代替 —— **没有图标不是错误，是常态。**
