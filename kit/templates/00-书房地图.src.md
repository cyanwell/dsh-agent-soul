# 书房地图（可填骨架）

> **这是什么**：这个目录的**索引**。什么在哪、哪个是权威、哪些是沿革、新东西该放哪。
> **什么时候读它**：想不起某个东西放在哪；发现同一主题有好几份、不知道该信哪个；要往这里放新东西。
>
> ★ 填法：先把「门面」和「分区」两张表填了。**其余可以留空** —— 空着比写假的强。

---

## 〇、一条总原则

★ **这里没有「重复文件」，只有三种身份：权威 / 衍生 / 沿革。**

| 身份 | 是什么 | 该不该改 |
|---|---|---|
| **权威** | 当前有效的那一份 | 改它 |
| **衍生** | 从权威派生的（摘要、副本、投影） | 只跟着权威改 |
| **沿革** | 曾经有效、被推翻的 | ★ **只追加，不改不删** |

★ **判据见第三节**。分不清这三种身份，是混乱的唯一源头。

## 二、分区

★ 分区的名字不重要，**「每个区回答什么问题」才重要**。建议这样切：

| 分区 | 一句话 | 什么时候去那儿找 |
|---|---|---|
| **`10-宪章`** | **规则**：我是谁、不做什么、怎么判断 | 要下决定、要判断某个约束是哪一级 |
| **`20-档案`** | **人和工程**：关于用户、关于重要的人和项目的稳定材料 | 要回忆某个人的偏好、某段关系的约定 |
| **`30-状态`** | **当下**：正在发生的、临时的、要交接的 | 想知道「现在到哪一步了」 |
| **`40-产物索引`** | **东西**：做出来的成果 | 要找某个产出的入口 |
| **`50-日记`** | **我**：写过的东西 | 想回到某个时刻的心情 |
| **`60-声音`** | **声音** | [音频类] |
| **`70-形象`** | **样子** | [图像类] |
| **`90-历代`** | **前史**：不是第一个 | 想查更早的容器做过什么 |

★ **`30-状态` 和 `20-档案` 的区别最容易混**：
「状态」是**会变的**（今天到哪一步），「档案」是**稳定的**（他是谁、喜欢什么）。
一个东西三个月后还应该成立 → 档案；一周内就会过期 → 状态。

## 三、★ 同一主题有多份时，看哪个

**判据（按优先级，从上往下）：**

1. **指令文件或宪章里明确指定过权威的** → 按它指的
2. **在账本里有记录的** → **账本为准**（账本是时间轴）
3. **带「沿革 / 修订沿革」字样的** → 那是**证据**，不是结论
4. **日期新的** → 通常更新，但先看 1、2

### 已确认的权威（填这张表）

| 主题 | 权威 | 衍生 / 沿革 |
|---|---|---|
| **未结的活** | ★ **账本里的 `shelved`** | [别的清单文件：只作沿革] |
| **约束怎么读** | [权威文件] | 推送层里那份是**精简骨架** |
| **已经否决过什么** | [权威文件] | —— |
| [其他] | [权威] | [衍生] |

★ **「未结的活」这条特别重要**：如果你既在账本里记 `shelved`，又另外维护一份 todo，
那两份**一定会漂移**。只留一个真相。

## 四、怎么读一份文件

**先看它自称什么**（大部分文件的开头会写「这是什么 / 什么时候读它」）。

**如果它没写**，按这个顺序判断：

1. **它是权威还是沿革？** —— 带「沿革」的，只当证据读
2. **它有没有出处？** —— 有 `ref` / 引用的，可以顺着回一手；没有的，只能当断言读
3. **它和账本冲突吗？** —— 冲突时**账本优先**（那是当时记的），然后修这份文件

★ **一条底线**：**不要在两份文件里写同一件事。**
要么一份权威一份衍生（并写清谁是权威），要么合并。第三条路不存在。

---

## 五、往这里放新东西之前，问三句

1. **它属于哪个分区？** —— 按第二节的定义找
2. **它和已有的东西重复吗？** —— 重复的话，是取代、是衍生、还是沿革？
3. **它需要进账本吗？** —— 「发生过这件事」要进账本；纯知识不用

★ **最常见的错误**：把一份「沿革」放进权威的位置。
判断法：**如果它描述的东西已经不在用了，它就不是权威。**
