# 重启 DSH 之后，怎么验判据①

> 判据①：MCP 适配器挂在真实 DSH 上跑通一轮 ——
> 宿主能调 `soul_index` 写帧、`soul_recall` 检索、`soul_persona` 取人格。

## 一、先确认挂上了

重启后，任何一个会话里看工具列表 —— 应该出现 6 个 `soul_*`：

```
soul_recall  soul_frame  soul_persona  soul_index  soul_sessions  soul_health
```

★ **判据：工具列表里能看到这些名字 = 真加载了。** 看不到就是没加载，别猜。

## 二、跑一轮真实调用（三步，缺一不可）

### ① soul_index —— 宿主写帧

说：**「用 soul_index 记一条，session 叫 dsh-test-001，内容随便写一句今天做了什么」**

预期：返回 `已索引 dsh-test-001#1`

### ② soul_recall —— 同一个宿主检索

说：**「用 soul_recall 搜一下刚才写的那句关键词」**

预期：返回 `[dsh-test-001#1] (user) ...` 带门牌

### ③ soul_persona —— 取人格

说：**「用 soul_persona 把人格层取出来给我看」**

预期：返回分层全文，**尾部有一行**：
```
已装 N 个文件，XXXXXB / 预算 80000B，裁掉: ...
```

★ **这一行是关键** —— 它证明「分层 + 可见裁剪」在工作，不是把文件硬拼起来。

## 三、出问题怎么查

| 症状 | 先看哪 |
|---|---|
| 工具列表里没有 soul_* | `D:\AI\dsh\home\mcp-hub\_apply-trace.log` 最后几行，看 `loadServers` 的 servers 数是 4 还是 3 |
| 调了报“工具不存在” | 同上 —— 说明进程还是旧的那份配置 |
| 调了超时 | agent-soul 的 stderr 有没有起来（手动跑一次 `node D:\AI\agent-soul\src\adapters\mcp.mjs`，看它是否立刻退出） |
| 能调但检索为空 | 数据目录对不对：默认 `D:/AI/agent-soul/data`，可用 `AGENT_SOUL_DATA` 覆盖 |

★ **手动起一次最快**：
```bash
node D:\AI\agent-soul\src\adapters\mcp.mjs
```
它会打一行 `[agent-soul] MCP server ready, 6 tools` 然后等 stdin。**能起就说明服务端没问题，问题在宿主侧。**

## 四、回滚

如果挂上之后 DSH 起不来或工具列表乱：

```
D:\AI\dsh\home\mcp-hub\servers.json.bak-before-agent-soul-1793986471426
```

复制回 `servers.json`，重启即可。**这个备份是我加条目之前复制的，字节级还原。**
