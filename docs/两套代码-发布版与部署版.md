# 两套代码：发布版与部署版（2026-11-02）

## 一句话

同一个零件有两个住处，**没有一个工具会告诉你它们差在哪** —— 这份文档是那条判据，
`tools/sync-deployed.mjs` 是它的可执行版本。

---

## 一、两个住处

| | A · 发布版 | B · 部署版 |
|---|---|---|
| 路径 | `dsh-agent-soul/plugins/<目录>/` | `<profile>/node_modules/<包名>/` |
| 本机实例 | `D:\AI\dsh-tools\dsh-agent-soul\plugins\` | `D:\AI\dsh\home\profiles\desktop\node_modules\` |
| 包名 | `dsh-agent-*` | `dsh-yanqing-*`（还有 `dsh-clock` / `dsh-riji` 等） |
| 含本机路径 | **不允许** | 允许（`D:\AI\memory\…`、`D:\AI\dsh\home\state\…`） |
| 含本机实验 | 不允许 | 允许（未验证的功能先在这里跑） |
| 给谁 | 任何 clone 这个仓库的人 | 只给这台机器 |

★ **A 里出现 `D:\AI\` 就是 bug**。仓库里有一条断言在守这个（`verify-packaging.mjs` 一类），
但只覆盖一部分文件 —— 改的时候自己看一眼。

---

## 二、什么时候该改哪边

| 场景 | 改哪边 | 然后 |
|---|---|---|
| 修一个所有人都有的 bug | **A** | 提交 → 部署到 B（`tools/deploy-client.mjs` 只管客户端半；纯宿主半手动 cp） |
| 只跟这台机器有关的（本机路径、本机实验） | **B** | 不要进 A |
| 在 B 上试验成功、要发布 | **A** | 先把 B 里那些本机专用的东西剥掉，再搬 |
| 不确定算哪种 | 先写进 `30-状态/` 里问 | 别直接改 |

★ **「从 B 搬到 A」是最容易出错的一步**：B 里有本机路径、包名也不同。
直接 `cp` 会把 `dsh-yanqing-*` 带进发布版。**必须逐个文件看 diff。**

## 三、现在差多少（2026-11-02 实测）

`node tools/sync-deployed.mjs` 输出：**15 / 15 个包有差异**。

- **走在前面的几个**（B 有 A 没有的）：pruner 的自动触发（+130 行，未验证）、huanqi-panel（+92 行）、memory（+8 行）
- **走在后面的几个**（A 有 B 没有的）：clock 的 client（202 → 349 行）、compaction（302 → 330）、riji（118 → 152）
- **只在 B**：`dsh-yanqing-chat` / `-line` / `-pet` / `-triad` / `-voice` / `comfyui-panel` / `mimo-agent-tools` / `clawbot` 等 20 个
- **只在 A**：`dsh-agent-mnemon-probe`

## 四、怎么查

```bash
node tools/sync-deployed.mjs                          # 列差异（只读）
node tools/sync-deployed.mjs --fail-on-diff           # 有差异就 exit 1
node tools/sync-deployed.mjs --deployed "<另一个 node_modules>"
```

## 五、三个已经踩过的坑

1. **不要用 mtime 判「谁新」。** 仓库文件的 mtime 会被 `git checkout` 刷新。
   第一版对账工具就是这么干的，报了 15 个假「部署落后」。
   要看方向：`git -C <仓库> log -1 --format=%cs -- plugins/<目录>`。
2. **包名不能直接比。** A 是 `dsh-agent-<x>`，B 是 `dsh-yanqing-<x>`。
   判据：剥掉前缀后尾段相同 —— `sync-deployed.mjs` 里的 `keyOf()`。
3. **`lib/` 要比。** 本机的 `dsh-yanqing-huanqi` 跑的是 `lib/index.js`（编译产物），
   而 `src/index.ts` 只在发布版有。排除 `lib` 会让你看不见真正的宿主机代码差异。

## 六、和 organs 那次的关系

`tools/sync-plugins.mjs` 是给旧的 `plugins → dsh-agent-organs` 用的，
那个仓库 2026-10-30 已弃用并删除 —— **它现在跑起来只会 exit 2**。
两个住处的关系从「三个」变成了「两个」，工具和文档一起换了。
