# 新用户接入 agent-soul v4

> 写给**完全没用过**的人。从拿到 exe 到宿主里能调 15 个工具，四步。

---

## 第 0 步：拿到文件

一个文件：`agent-soul.exe`（约 35 MB，自带 node 运行时，**不需要装任何东西**）。

放到哪都行 —— 桌面、D 盘某个目录。**它自己会解压到固定位置**，你放的地方只用来双击。

---

## 第 1 步：双击

会出现一个控制台窗口，几秒后长这样：

```
  agent-soul
  ─────────────────────────────
  GUI      http://127.0.0.1:7310
  MCP      http://127.0.0.1:7310/mcp   ← 别的 harness 接这个地址
  工作区   C:\Users\<你>\AppData\Local\agent-soul
  数据     C:\Users\<你>\AppData\Local\agent-soul\data
  会话     0 个
  人格     未配置
  ⚠ 还没配 apiKey —— 在 ...\config.json 里填 llm.apiKey
```

**★ 这三行是你要的全部信息**：

| 行 | 拿来干什么 |
|---|---|
| `GUI` | 浏览器打开，看数据/器官/参数/设置 |
| **`MCP`** | **贴进你的 harness 配置 —— 就是这一行的事** |
| `工作区` | 配置和数据都在这儿 |

★ **端口不是固定的**（默认 7310，被占了会自己换）。**以屏幕上打印的为准**，别照抄文档里的数。

---

## 第 2 步：填 apiKey（只有想让它自己起回合才需要）

编辑 `工作区\config.json`：

```json
{"llm": {"apiKey": "sk-你的key"}}
```

或者设环境变量 `AGENT_SOUL_KEY`。**填完重启 exe。**

★★ **如果你只想要「记忆与检索」**（大多数人的用法）—— **这一步可以跳过**。
不填 key 时，`soul_query` / `soul_recall` / `soul_file` / `soul_persona` / `soul_ledger` **全都照常用**，
只有 `soul_autonomy`（自主循环）和对话页需要它。

---

## 第 3 步：接到你的 harness

### 方式 A —— HTTP（最省事，推荐先试这个）

配置里写：

```json
{"serverName": "agent-soul", "transport": "http", "url": "http://127.0.0.1:7310/mcp"}
```

★ **端口换成你屏幕上那个。**
★ 服务**必须开着**（exe 窗口别关）。

### 方式 B —— stdio（宿主自己拉进程，不用先开 exe）

```json
{"serverName": "agent-soul", "transport": "stdio",
 "command": "C:/Users/<你>/AppData/Local/agent-soul/runtime/node.exe",
 "args": ["C:/Users/<你>/AppData/Local/agent-soul/src/adapters/mcp.mjs"]}
```

★★ **这两个路径是固定的**（解压位置不随你放 exe 的地方变）：

| 什么 | 路径 |
|---|---|
| node | `%LOCALAPPDATA%\agent-soul\runtime\node.exe` |
| MCP 入口 | `%LOCALAPPDATA%\agent-soul\src\adapters\mcp.mjs` |

把 `%LOCALAPPDATA%` 换成 `C:\Users\<你>\AppData\Local` 就能直接粘。

★ **stdio 那条腿不用先开 exe** —— 宿主每次启动自己去拉 node 进程。
★ 但**第一次必须先双击一次 exe**，让它把文件解压出来。

### 各宿主的配置文件在哪

| 宿主 | 位置 |
|---|---|
| **DeepSeek Harness** | `%DSH_HOME%\mcp-hub\servers.json`（本机 = `D:\AI\dsh\home\mcp-hub\servers.json`） |
| **Claude Desktop** | `%APPDATA%\Claude\claude_desktop_config.json` 的 `mcpServers` 段 |
| **Codex / 其它** | 找它文档里说的「MCP servers」配置，形状大同小异 |

---

## 第 4 步：确认接上了

宿主里应该多出 **15 个工具**，名字都是 `soul_` 开头。

**最快的自检**：调一次 `soul_context`（不用参数）。

```
现在：2026-11-07 03:52（星期六）
上下文：0 tokens / 1048576（0.0%）
★ 这是本软件自己这个容器的水位，不是你宿主 harness 的。
```

**看到这几行 = 通了。**

---

## 不接宿主也能验（30 秒）

不用管配置，直接喂一行 JSON-RPC 给它：

```powershell
"{\"jsonrpc\":\"2.0\",\"id\":1,\"method\":\"initialize\",\"params\":{}}" | 
  & "$env:LOCALAPPDATA\agent-soul\runtime\node.exe" "$env:LOCALAPPDATA\agent-soul\src\adapters\mcp.mjs"
```

看到 `{"jsonrpc":"2.0","id":1,"result":{"serverInfo":{"name":"agent-soul"...` 就是活的。

★ 这条**跳过了所有宿主配置问题** —— 如果它通、宿主不通，问题在宿主配置，不在这软件。

---

## 四个最常见的坑

### ① 换了新版 exe，我的 key 和数据还在吗

**在。** 2026-11-07 修过一个会吃掉它们的 bug，现在解压前会把 `config.json` 和 `data\` 挪出去、解压完挪回来。
实测：删版本戳强制重解压后，`config.json` 的自定义字段、`llm.apiKey`、`data\sessions\` 里的会话**全部还在**，代码是新的。

### ② stdio 报「找不到 node.exe」

**你还没双击过 exe。** 先双击一次，让它解压。

### ③ HTTP 连不上

三个可能，按顺序查：

1. **exe 窗口关了吗** —— HTTP 那条腿要求服务开着
2. **端口抄错了吗** —— 文档里的 7310 只是默认值，被占了会换。**看屏幕**
3. **`127.0.0.1` 还是 `localhost`** —— 用 `127.0.0.1`，`localhost` 在有 IPv6 的机器上可能解析到 `::1` 而服务只绑了 `127.0.0.1`

### ④ 工具列表是空的

先跑上面那条「不接宿主也能验」。通了 → 宿主配置有问题（多半是 JSON 里有全角引号、或路径没用正斜杠）。不通 → 软件本身没起来。
