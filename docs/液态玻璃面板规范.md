# 液态玻璃（Liquid Glass）面板规范 · v1

> 2026-11-01 从回声哨兵面板的改版里抽出来的。
> 目的：让本机所有 DSH 插件面板看起来是一套东西。
>
> ★ **这份规范的第一条不是审美，是一条坑** —— 见下面「一、先看这条」。

---

## 一、★ 先看这条：不许用 `backdrop-filter`

2026-10-02 实测：`backdrop-filter` 会让卡片成为**独立 GPU 合成层**，
滚动时整张卡连同内容一起重绘 → **「滚轮一动整个界面都在闪」**。
当时的定位过程写在 `dsh-agent-soul/plugins/echo/client.js` 开头的注释里。

**所以「玻璃感」靠四样东西撑，不靠真毛玻璃：**

1. 半透明底色（`--glass` 的渐变）
2. 有色散的内高光（`box-shadow: inset 0 1px 0 rgba(255,255,255,...)`）
3. 厚度的上下边（`inset 1.5px 0 0` / `inset -1.5px 0 0`）
4. 大而散的外投影

★ **如果哪天真的想加回 `backdrop-filter`**：先在一个有 300 个图标的页面上滚一遍，
确认不闪。**没滚过就别加。**

## 二、★ 第二条坑：玻璃和文字必须**成对绑定**

这是回声面板「白底白字、整片糊」的真正根因：

```css
/* ✗ 错的写法 */
--ink: var(--dsw-alias-label-primary, #16202c);   /* 读宿主给的字色 */
--glass: linear-gradient(...rgba(255,255,255,.86)...);  /* 玻璃却是白的 */
```

宿主是深色主题时，`--dsw-alias-label-primary` 给的是**浅色字**，
而玻璃是**近白底** → 白底浅字。

**判据：玻璃的亮度和文字的亮度，必须在同一个地方一起定义。**

```css
/* ✓ 对的写法：两个变量在同一行里成对给出 */
:root{
  --glass: linear-gradient(148deg, rgba(255,255,255,.86), rgba(255,255,255,.62));
  --ink: #16202c;      /* 玻璃白 → 字深 */
  --dim: #42536b;
  --faint: #5b6b80;
}

/* 深色变体：玻璃变深，字才跟着变浅 —— 成对切换，不是各改各的 */
[data-tone="dark"]{
  --glass: linear-gradient(148deg, rgba(30,38,50,.88), rgba(22,29,40,.72));
  --ink: #e8eef6;
  --dim: #a7b6c8;
  --faint: #7d8da3;
}
```

★ **不要 `@media (prefers-color-scheme)` 一刀切** —— 宿主主题由 DSH 自己的
`data-tone` / 皮肤状态决定，跟系统深色模式不一定一致。

## 三、token 表（直接抄）

```css
.yq-root{
  /* 语义色 */
  --ok:#34d399; --warn:#fbbf24; --error:#f87171; --pending:#60a5fa;

  /* 前景三层 —— 与 --glass 成对 */
  --ink:#16202c; --dim:#42536b; --faint:#5b6b80;

  /* 玻璃 */
  --glass:linear-gradient(148deg,rgba(255,255,255,.86),rgba(255,255,255,.62));
  --edge:rgba(16,32,52,.14);
  --lift:inset 0 1px 0 rgba(255,255,255,.70),
         0 8px 26px rgba(16,32,52,.12),
         0 1px 2px rgba(16,32,52,.08);

  /* 深色面上的浮起（用于按钮、凹槽） */
  --sunken:rgba(16,32,52,.055);

  /* ★ 动效曲线 */
  --spring:cubic-bezier(.34,1.56,.64,1);   /* 过冲一点再回来 */
  --swift:cubic-bezier(.22,.61,.36,1);     /* 快起慢收 */

  --code-bg:rgba(16,32,52,.06);
  --accent:#60a5fa;

  /* 高光跟随指针（JS 写这两个） */
  --lg-mx:50%; --lg-my:0%;
}

/* 让 CSS 变量能被 @keyframes 平滑推进 */
@property --lg-a{ syntax:"<angle>"; initial-value:0deg; inherits:false }
```

### 组件底色速查（白玻璃上）

| 组件 | 用什么 | ✗ 别用 |
|---|---|---|
| 按钮底 | `rgba(16,32,52,.075)` | `rgba(255,255,255,.055)` ← 白玻璃上看不见 |
| 按钮边 | `1px solid rgba(16,32,52,.20)` | `rgba(255,255,255,.13)` |
| 分段器凹槽 | `rgba(16,32,52,.055)` + `inset 0 1px 2px` | `rgba(0,0,0,.24)` ← 突兀的黑块 |
| chip | `rgba(16,32,52,.045)` / 边 `.10` | 白色低透明度 |
| 选中态 | `rgba(96,165,250,.92)` 实色蓝 | `.36` 透明度 ← 太淡 |

★ **判据：在白玻璃上，凡是想「浮起来」的都加**深**色低透明度，不是白色。**

## 四、四件动效（照抄）

### ① 边缘流光 —— 玻璃的「湿润感」

```css
.yq-glass::after{
  content:""; position:absolute; inset:0; border-radius:inherit;
  pointer-events:none; padding:1px;
  background:conic-gradient(from var(--lg-a,0deg),
    transparent 0deg,
    rgba(255,255,255,.75) 26deg,
    rgba(160,205,255,.35) 52deg,
    transparent 96deg);
  -webkit-mask:linear-gradient(#000 0 0) content-box, linear-gradient(#000 0 0);
  -webkit-mask-composite:xor;
  mask:linear-gradient(#000 0 0) content-box, linear-gradient(#000 0 0);
  mask-composite:exclude;
  opacity:.5;
  animation:lg-edge 11s linear infinite;   /* ★ 慢。快了像加载动画 */
}
@keyframes lg-edge{ to{ --lg-a:360deg } }
[data-tone="dark"] .yq-glass::after{ opacity:.75 }   /* 深色玻璃上要更亮才看得出 */
```

### ② 弹簧过渡

```css
.yq-glass, .yq-btn, .yq-seg button, .yq-check{
  transition-timing-function: var(--spring);
}
```

### ③ 抬起与回弹

```css
.yq-metric{

  will-change:transform;

.yq-metric:hover { transform:translateY(-2px) scale(1.012) }

.yq-btn:hover:not(:disabled){ transform:translateY(-1px) }
.yq-btn:active:not(:disabled){ transform:translateY(0) scale(.955) }
```

### ④ 镜面高光跟随指针

**CSS 侧**：

```css
.yq-hero{
  background-image:
    radial-gradient(220px circle at var(--lg-mx) var(--lg-my),
      rgba(255,255,255,.42), transparent 68%),
    var(--glass);
}
[data-tone="dark"] .yq-hero{
  background-image:
    radial-gradient(240px circle at var(--lg-mx) var(--lg-my),
      rgba(150,200,255,.16), transparent 70%),
    var(--glass);
}
```

**JS 侧 —— ★ 两条纪律**：

```js
// 1) 只挂在**一张**大卡上。每张卡都挂 mousemove，事件频率乘以卡数。
// 2) rAF 节流：一帧最多写一次 CSS 变量，样式重算被压到 60fps 以内。
onPointerMove: (e) => {
  if (!motion) return;
  const el = e.currentTarget;
  if (el._lgRaf) return;
  el._lgRaf = requestAnimationFrame(() => {
    el._lgRaf = 0;
    const r = el.getBoundingClientRect();
    el.style.setProperty("--lg-mx", ((e.clientX - r.left) / r.width  * 100).toFixed(1) + "%");
    el.style.setProperty("--lg-my", ((e.clientY - r.top ) / r.height * 100).toFixed(1) + "%");
  });
},
onPointerLeave: (e) => {
  e.currentTarget.style.setProperty("--lg-mx", "50%");
  e.currentTarget.style.setProperty("--lg-my", "0%");
},
```

## 五、★ 必须有开关（不是可选项）

```css
/* 用户关掉动效：全局一刀切 */
[data-motion="0"] *,
[data-motion="0"] *::before{ animation:none !important; transition:none !important }

/* 系统和用户要求减弱 */
@media (prefers-reduced-motion: reduce){
  * , *::before{ animation:none !important; transition:none !important }
}
```

**面板自己再给一个「动效」按钮**（存 `localStorage`），点了就设 `data-motion="0"`。
★ 理由：`prefers-reduced-motion` 覆盖不到「我觉得卡」这种情况。

## 六、响应式：判据是**面板自己的宽度**，不是屏幕

```css
/* 兜底：视口宽度 */
@media (max-width: 720px){
  .yq-metrics{ grid-template-columns:repeat(2,1fr) }
  .yq-hero{ flex-wrap:wrap }
}
@media (max-width: 460px){
  .yq-metrics{ grid-template-columns:1fr 1fr; gap:7px }
  .yq-metric .n{ font-size:23px }
}

/* 更好的：容器查询 —— 面板被拖窄 / 分屏时才准 */
@container (max-width: 620px){
  .yq-metrics{ grid-template-columns:repeat(2,1fr) }
}
```

★ 这两条**要一起写**：容器查询不支持的宿主会走媒体查询兜底。

## 七、几条踩过的经验

| 现象 | 原因 | 做法 |
|---|---|---|
| 白底白字 | `--ink` 读了宿主变量，`--glass` 是白的 | 两者成对定义（第二节） |
| 最重要的数字反而最淡 | 用了 `--faint` | 数字用 `--ink`，label 用 `--dim` |
| 单条数据拉满整行，像报错横幅 | `flex:1` 没上限 | 加 `max-width:18px` + `justify-content:flex-start` |
| 按钮在白玻璃上「没有边界」 | 用了白色低透明度 | 改深色低透明度（第三节） |
| 深色主题下面板糊 | 只写了浅色那套 | 必须有 `[data-tone="dark"]` 整套 |
| 转半天没人觉得好看 | 流光转太快 | 11 秒一圈，慢到像呼吸 |

## 八、验收怎么验（不靠肉眼猜）

**用 Edge headless 直接出图** —— `browser_*` 工具要 cooperate sync、
系统浏览器容易截错窗口，这条路最稳：

```bash
msedge --headless=new --disable-gpu --hide-scrollbars \
  --screenshot=out.png --window-size=1180,1500 \
  --virtual-time-budget=3000 \
  "http://127.0.0.1:8765/preview.html"
```

★ 前提：先用 `python -m http.server` 起个静态服务（`file://` 会被拒绝）。

**再看图**，逐条对：
- 每一级文字都读得清（`--ink` / `--dim` / `--faint` 三层都有内容）
- 按钮看得出是按钮
- 玻璃边缘有一道会走的亮线
- 窄宽度下指标卡变 2 列
