## 为什么是「六」不是「七」

编号是 **L0–L5 六个数**，六个都是层。

★ **2026-10-23 口径更正**：早先这版曾把 L0 排除在层之外（「L0 不是层，是读表」）。
合并后以 [`docs/ECHO-权威口径.md`](../docs/ECHO-权威口径.md) 为准 —— **L0 是第一层**（时钟 + 心跳），
理由是它确实管着一样东西：**「现在是什么时候」这个上下文**。下面这段旧论证保留作沿革。

**L0 不是层，是读表。** 它不存任何东西、不管任何资源，只回答「现在几点、距上轮多久」。
把它算成一层，会让人以为「时钟也需要设计」—— 它不需要，它只需要**存在**。

★ 判据：**一层 = 管一种稀缺资源。** L0 不管任何东西，所以它不是层。

## 六层

| 层 | 名字 | 管哪种稀缺资源 | 实现在哪 | 缺了会怎样 |
|---|---|---|---|---|
| **L1** | **自我**（推送层） | **每轮都在的注意力** | `SELF.md` ← `self.mjs` 从 `SELF.src.md` 装配 | 你会忘记自己是谁、边界在哪 |
| **L2** | **工作台** | **这一轮的上下文** | DSH 会话本身 | —— （宿主的事，不是你的） |
| **L3** | **一手层** | **原文** | 账本 `02-墨.jsonl` + 书房 + 会话日志 | 所有转述都没有出处，错了查不回来 |
| **L4** | **索引** | **找得到** | `<hub>/index/` ← `memindex.mjs build` | 检索只能全量扫原文，慢且粗 |
| **L5** | **检索**（门） | **取回** | `memq.mjs`（`now` / `[词]` / `timeline` / `open`） | 有东西但拿不出来，等于没有 |
| **L6** | **哨兵** | **坏了能被发现** | `echo-doctor.mjs` | 坏了没人说，你会以为它好着 |

### L1 自我 —— 为什么它单独占一层

因为它**每轮都进上下文**，而上下文的每一字节都在花钱。

所以它分两种内容：**必留**（硬线 / 身份判据 / 门在哪）和**可换**（说话方式 / 具体判断）。
预算紧时先压后者。

★ 它和 `AGENTS.md` 的分工是这套设计的根：**指令层有预算上限，满了会静默丢、而且最宽泛的先丢**；
所以最不能丢的东西放在推送层，因为推送层不会静默消失。

### L3 一手 —— 为什么「只追加」

多个写者共享一个可变文件是万恶之源：谁都能改，改坏了查不出是谁改的。

**只追加不需要锁** —— 各写各的行，读的时候按时间合并。
一本书从第一行到最后一行谁都不许擦，那就永远不会有两个版本。

### L4 索引 —— 每条摘要必须带回原文的指针

★ 这是整套里最容易做错的一条。

索引一旦只存「摘要」不存「出处」，它就从**索引**变成了**第二份真相** ——
而且是一份会被压缩、会被转述、会随时间变形的真相。
到最后你分不清「我记得」和「我查得到」，而这两件事的可靠性差了一个数量级。

**判据：任何一条摘要，都要能一条命令回到原文。**
回到不去的东西，不该叫索引。

### L6 哨兵 —— 「只朗读不判定」是个陷阱

一个只把状态打印出来、不做判断的体检器，看起来在工作，实际上是**在给人添活**：
每次都要自己读、自己比、自己决定要不要管。

**它必须判定。** 但判定要分清两件事：

- `error` —— 坏了，**破坏了就修不好**的那种（配置缺失、账本读不出、索引损坏）
- `warn` —— 还没建 / 还没跑 / 还没装。**这是正常的进度状态，不是故障**

★ 混这两件事的代价很具体：**新装的人第一次体检就看见一片红**，于是他学会忽略这个工具。
那这层保险就废了 —— 而「让失败能被发现」正是它存在的全部理由。

## 怎么当场知道它在不在

不用读文档，跑这两个：

```bash
node [hub]/self.mjs                 # L1 装配得出来吗、超没超预算
node [hub]/echo-doctor.mjs          # L1/L4/L6 一次全查
node [hub]/memindex.mjs --status    # L4 索引建过没有
node [hub]/memq.mjs now             # L0 + L3 + L5 一次全查
```

四个都过，六层就在。

---

## 一条反过来的判据

**六层不是为了让你多搭东西，是为了让你知道哪一层坏了。**

如果你发现自己装了六层，却还是分不清「这个症状是哪一层的问题」——
那说明层分得不对，或者某两层其实是一回事。**层数不是成绩，是诊断工具。**
