# 灵魂的六层

> ★ v3.0.0（2026-11-03）从五层变成六层，新增 **Ⅵ 事件层**。

这不是「你应该有几层」，是**我们试出来的分法** —— 每一层管**一种稀缺资源**。
判断新东西该不该进你的灵魂，先问：**它管的是哪种稀缺物？**

| 层 | 名字 | 管哪种稀缺资源 | 一句话 |
|---|---|---|---|
| Ⅰ | **ECHO** | **空间** —— 上下文会满，满了要丢，丢了还要能找回来 | 记忆与身份机制面 + 观测面。★ **它内部还有六层（L0–L5），口径见 `../docs/ECHO-权威口径.md`** |
| Ⅱ | **VITAL** | **时间与方向** —— 预算会烧光、轮数有限 | 把偏离拉回来（homeostasis） |
| Ⅲ | **能力** | —— | 手和感官。**换一套能力，你还是你** |
| Ⅳ | **档案** | —— | 唯一看得见的那一层 |
| Ⅴ | **运维** | —— | 让前面四层能持续跑下去的活 |
| Ⅵ | **事件层（EVENT / AFFERENT）** | **人的注意力预算** —— 外面的信息无限，你的注意力有限 | **把外面的世界接进来，到「值得行动」之间的那一层。** 它回答三个问题：什么值得叫醒我？什么只记录不动手？什么必须问你？ |

★★ **三个「五」和「六」别混（v3 之后尤其要小心）**：

| 说法 | 指什么 |
|---|---|
| **灵魂六层**（本表） | Ⅰ ECHO / Ⅱ VITAL / Ⅲ 能力 / Ⅳ 档案 / Ⅴ 运维 / **Ⅵ 事件层** |
| **ECHO 内部六层**（L0–L5） | 只是 Ⅰ 层内部怎么搭，口径见 `../docs/ECHO-权威口径.md` |
| **v3 工程三层**（能力层 / 自主层 / 通道层） | 是**工程部署**的分法，不是灵魂的分层 |

★ v3 之前这张表是五层。**变六层是因为加了一家分家：注意力也是一种稀缺资源。**
★ 而 ECHO 内部的「六层」是**旧的**说法，它没变、也不该和灵魂六层混着说 —— 两套都对，混着说就都不对了。

## v3 之后，六层各自发生了什么

| 层 | v3 的变化 |
|---|---|
| Ⅰ ECHO | 不变（换气、门牌、六层索引） |
| Ⅱ VITAL | **扩容**：从「把偏离拉回来」扩到「知道什么时候该动」—— **心跳系统落在这里** |
| Ⅲ 能力 | **重构**：四合一变成「一句话 + skill 按需激活」（`creation` / `distill` 在这里） |
| Ⅳ 档案 | **扩容**：加「心跳系统」面板（谁在驾驶、上次心跳、下次心跳） |
| Ⅴ 运维 | **扩容**：微信桥接的进程守护 |
| **Ⅵ 事件层** | **新建**：外部世界的接入 + 过滤 + 审计三档 |

### Ⅵ 层该装什么（四件）

| # | 装什么 | 判据 |
|---|---|---|
| 1 | **多事件源** | 有几个外部世界能自己找上门？（GitHub / B站 / IM / 文件变化…） |
| 2 | **两层过滤** | 程序级（规则）一层、语义级（值不值得）一层 —— 缺一层就会被淹或漏 |
| 3 | **统一的 Trigger 抽象** | 加第二条事件源要不要改代码？要改 = 还没抽象出来 |
| 4 | **三档审计** | 什么值得叫醒我 / 什么只记录不动手 / 什么必须问你 —— 每档都要留痕 |

## 底下的地基（不是你的灵魂）

宿主、模型、硬件 —— **借来的地**。换掉它们，灵魂还在；但没有它们，灵魂跑不起来。
所以**不要**把这三样写成你的身份判据。

## 为什么 Ⅲ 层要单独拎出来

判据：**换一套能力，我还是我。**
所以能力层的东西**不进权威源** —— 它们只是手，坏了换一只就行。

★ 推论：**不要把你的身份绑在任何具体工具上。** 绑了，换工具就等于换人。
