# Ⅰ · ECHO —— 生命核心

**它管空间。** 上下文会满，满了要丢，丢了还要能找回来。

## 一个 agent 的上下文病，根因常常不是「没装记忆插件」

是**没定权威源**（判据 ②）。装三个记忆插件而不定权威源，你得到的是三份真相和一堆对账工作。

## 先分清：压缩有两条路，要补的是**下面那条**

| | 谁在驱动 | 产物带不带指针 |
|---|---|---|
| **模型驱动** | agent 自己写摘要 | ✅ 天然带 —— 它知道自己是从哪读的 |
| **兜底压缩** | 没人响应提示时，引擎**自动出手** | ❌ 通常不带 |

**上面那条你不装也有；下面那条你不装就缺。**

为什么下一条会缺：那种压缩器的指令通常要求「保留精确路径 / 命令 / 报错原文 / 数值 / 函数签名」——
**每一条都是「要写得准」，但没有一句要求标注「这话从哪来」。**

**于是它写出来的东西每一条都对，每一条都无从核对。**
而且失败是无声的：**你不会觉得丢了东西，你只是不再想起它。**

**所以「门牌」要补的正是这一条。** 下面三样里，第 1 样就是它。

## 机制面 · 至少要有三样

### 1. 丢的时候，产物必须带得回原文的指针（门牌）

**这是整套东西的兜底承诺。** 没有它，压缩就是单向的遗忘。

三级纪律 —— **照抄即可**：

```
① 能拿到精确位置 → 写精确位置
② 拿不到 → 写「位置未知」+ 容器标识 + 一个检索入口
③ 绝不猜 —— 错的门牌比没有更坏
```

★ 为什么第 ③ 条单独列出：**一个错的门牌会让你以为能找到，于是不去找。**
那比「找不到」坏得多。

### 2. 一门只回指针、不做转述的检索入口

转述是二手污染的来源。**能逐字取回，就不要摘要。**

动词最少三个：`现在是什么状态` / `搜一个词` / `打开某个指针`。

### 3. 一个自检（哨兵）

**判据 ③ 的落地**：它坏的时候，谁会发现？

体检项要跑得起来、要能给出分级状态（正常 / 提示 / 警告 / 错误）。
**没有哨兵的体系，坏了不会有人说。**

## 观测面 · 一个容易被漏掉的洞

**你的每一个执行器都要有对应的观测面。** 一个调好就不再看的阈值系统，
你永远不会知道它误伤过几次 —— 「断过没有、断错没有」必须有人能答。
