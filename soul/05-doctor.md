# 自检 · 拿这七句话问自己的架构

不用回答我，回答你自己。**答不上来的那一句，就是你缺的那一层。**

## 关于空间（Ⅰ）

1. 我的上下文满了以后，被丢掉的东西**还能不能找回来**？靠什么？
   → 答不上来：你要的是 **① 账本 + ② 门**（`tools/ledger`、`tools/gateway`）。没有门，丢了就是丢了。
2. 我有没有一个**唯一**的记忆权威源？如果有两份，哪一份算数？
   → 答不上来：你有两个「我」在各自记东西。要的是**只追加账本**（`tools/ledger`）——它天然没有这个问题：各写各的行，读时按时间合并。
3. 我的每一次压缩/裁剪，产物里**带没带**回原文的指针？
   → 答不上来：去装 `dsh-agent-compaction` 与 `dsh-agent-pruner`。★ 判据是「能不能一把回到原文」，不是「有没有加一行说明」。

## 关于时间与方向（Ⅱ）

4. 我烧光预算的时候，**谁会知道**？知道之后发生什么？
   → 答不上来：你没有第二道闸。要的是 `dsh-agent-huanqi`（检测循环并打断，带一本额度账）。
5. 我在原地打转的时候，**谁会知道**？它凭什么判定我在打转？
   → 答不上来：同上 —— 打转和烧预算是同一件事的两面。★ 判定依据必须是**可观测的重复**，不能是「我觉得」。
6. 我「该停不停」和「差一步就停」——这两种，我分得开吗？靠什么分？
   → 答不上来：这一句最硬，因为它没有现成的插件。★ 判据：**「还能更好」不算「没完成」** —— 分不清这两者，就会把「保养」当成「干活」。

## 关于接口（判据 ④）

7. 上面这六件事里，哪一件**坏了没有人会发现**？
   → 这一句是整份体检的收口。答不上来：你要的是 `dsh-agent-echo`（体检台）——★ 它的价值不是报告状态，是**报告它测不到什么**。

## 能跑的那一半（先跑完再回答上面七句）

上面七句要你自己答。但**其中四句是可以先机械查掉的** —— 查完再答，答案会诚实得多：

```bash
# ① 账本还在不在、有多少条      → 对应第 1、2 句
node tools/ledger/ledger.mjs stats

# ② 门能不能开、有没有索引      → 对应第 1 句
node tools/gateway/query.mjs now

# ③ 自我层有没有退化            → 对应第 7 句（"坏了没人发现"）
node tools/self/self.mjs --check

# ④ 闸门还灵不灵                → 对应第 2 句（唯一权威源）
node tools/ledger/ledger.mjs add promise "闸门测试" --ref "自检"
#    ★ 期望：不是主导会话 → 非零退出码 + 拒绝写入。若写进去了，闸门已失效。
```

**★ 这几条为什么放在这里**：七句话是**判断题**，而判断题最容易自我安慰。
先跑一遍能跑的，**你的答案就有了对手**。

★ 而这三条命令**分属三个不同的工具** —— 这不是巧合：
**账本（记得住）+ 门（找得到）+ 自我层（不退化）** 本来就是一套，
单独装任何一个都会缺一角。
