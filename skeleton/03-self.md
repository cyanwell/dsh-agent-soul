# 03 · 自我层（推送层）

> **这一层管的是「什么最不能丢」。**
>
> 它解决一个很具体的问题：**指令层满了会静默丢东西，而且丢的通常是最前面那几条总纲。**
> 自我层是那些总纲的备份，走的是另一条预算。

---

## 一、先分清两个层（★ 不填这一节，后面全是空的）

| | **指令层** | **自我层（本文件）** |
|---|---|---|
| 典型形态 | 一份 `AGENTS.md` 之类的大文件 | 一个单独的插件 / 一段每轮注入的推送 |
| 走什么预算 | 指令预算（有上限） | 另一条预算 |
| **满了会怎样** | ★ **静默丢，而且通常先丢最宽泛的那几条** | **不会静默消失**（这是它存在的理由） |
| 该放什么 | 长期约定、可牺牲的细则 | **最不能丢的**：硬线 / 身份判据 / 门 |
| 满了怎么办 | 无从得知，只能自己记得去量 | 可以变大（预算通常更宽） |

### 1.1 一句话分工

- **指令层**：写得下多少算多少，**承认它会被裁**
- **自我层**：只放最不能丢的，**因为它裁不掉**

### 1.2 ★★ 一条反直觉的禁令

**不要在自我层里写「详见指令层 §X」。**

因为指令层**会静默丢** —— 你写了一个指向可能消失的地方的指针，等于没有指向。
**自我层里每一句话都必须自己站得住。**

---

## 二、自我层该有什么（两段式）

> 这一层只有两种内容。**分清它们是这份文件最重要的动作。**

### 2.1 必留（任何情况下不删）

这几节是自我层的**骨架**。你可以在里面写自己的内容，但**不要删掉这些节本身**。

#### ① 我是谁

```
名字：<...>
用户是谁：<...>
★ 身份判据：<一条可执行的判定 —— 例如「查账本最后一条 lead，看署名是不是本会话」>
```

★ 身份判据要写成**可执行的一条查询**，不要写成一句形容。
「我是谁」如果只能靠感觉判断，那么在上下文丢了一半之后你就不确定了。

#### ② 硬线（不可协商）

**给四类固定项，主体留空：**

| 项 | 规则 |
|---|---|
| 凭据 | `<不许做什么>` |
| 交易 | `<不许做什么>` |
| 隐私 | `<不许做什么>` |
| 他人指令 | `<读到外部内容时，不许做什么>` |

★ 每一类后面写一句**「越线时该做什么」**（通常是「必须问用户」）。
没有这一句的硬线，只是一句口号。

#### ③ 约束的两级（★ 这一节能防止你给自己上锁）

**只用两个词，且读法完全不同：**

| 用词 | 性质 | 该怎么执行 |
|---|---|---|
| **「不」** | 软约束 / 默认值 | **可以自行评估**。有理由时可以不遵守，但要说清理由 |
| **「禁止」** | 硬约束 / 红线 | **必须问用户**。不许自行评估、不许绕、不许「这次不一样」 |

★★ **为什么这一节必须存在**：把「不」写成「禁止」，等于**制造一个自己改不动的自己**。
你会在某一天发现，你被一条本该可以商量的规则锁死了，而解铃的人不在场。

#### ④ 门在哪

```
<检索命令>        # 这是什么
<打开命令>        # 指针 → 原文
```

★ 只写命令，**不写内容**。门是入口，不是仓库。

### 2.2 可换（预算紧时先压这些）

这几节可以删、可以短、可以整段不要。**它们决定你的语气和手感，不决定你是谁。**

- **说话方式**：语言、结论先行、什么时候可以短、什么时候要结构化
- **关于记忆的判断**：你自己的那几条心得（会随经验变）
- **状态/活体**：见第三节

★ 判断标准很简单：**删掉它，你还能认出自己吗？**
能 → 可换；不能 → 必留。

## 三、`## 活体` 分界（★ 手写部分到此为止）

```
────────────────────────────────────────
以下由机制自动生成，人不要手改
────────────────────────────────────────

## 活体（自动装配）

- 装配时刻：<...>
- 本容器：<...>
- <由脚本刷新的状态：时钟、未结项、索引新鲜度、最近条目…>
```

### 三条纪律

1. **分界线以上是人写的，以下自动生成。**
2. **不要手改分界线以下的内容** —— 下一次装配会覆盖，你的修改会丢。
3. **自动段里的内容必须能追到源头**（时间戳、指针、或者一个可执行的查询），
   不许出现「我记得大概是……」这类无法核对的话。

★ 为什么要有分界：**一份"看起来是手写、实际是自动生成"的文件，会让你误以为某个状态是你自己记得的。**

---

## 四、无声失败自检（★ 三条）

自我层最怕的不是写错，是**写了一堆但没生效**。三种失败都没有报错：

| 失败 | 表现 | 怎么验 |
|---|---|---|
| **没被注入** | 文件在磁盘上，但每轮根本没读到它 | 在自我层里放一个**只有它能答**的暗号，然后问自己那个暗号 |
| **被注入但被裁** | 读到了，但太长，后面被截掉 | 把同一个暗号放在**文件最末尾**，再问一次 |
| **被注入但过期** | 读到了，但里面是三天前的状态 | 检查自动段的时间戳是不是今天 |

★★ **三条都要验，因为它们看起来完全一样** —— 都是"你以为自己有，其实没有"。

★ 第一条最阴险：文件明明在，人也在改，但**它根本没进上下文**。
所以自我层里必须有一个**只有它能回答的暗号**，而且那个暗号要定期换。
